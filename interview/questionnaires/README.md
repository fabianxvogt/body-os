# Short questionnaires

Optional, validated screening instruments the agent can administer in a check-in or review and store
as a `questionnaire` event (`name`, `items` [item scores], `score`, `interpretation`). They are
**screens, not diagnoses** — follow [SAFETY.md](../../SAFETY.md) for high scores.

| Name | When | File |
|---|---|---|
| `phq4` | weekly (e.g. Sunday review); mood and anxiety during behaviour change | [phq4.md](phq4.md) |
| `cudit_r` | baseline day 0 and day 14, then monthly while reducing cannabis | [cudit-r.md](cudit-r.md) |

Ask the items one message at a time or as a numbered list the user answers in one line ("1:2 2:1 3:0 4:1").
Wording below is a plain-language working translation for self-tracking; the validated originals are
cited in each file. Record the questionnaire `name` exactly as listed.
